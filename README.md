# أبو أديب — Portfolio (AI Creative Portfolio)

موقع بورتفوليو احترافي، عربي بالكامل (RTL)، مبني بـ HTML/CSS/JavaScript الأصلي بدون أي إطار عمل (لا Bootstrap ولا Tailwind ولا jQuery).

## البنية

```
index.html
css/
  style.css         نظام التصميم: الألوان، الطباعة، الفراغات، الظلال (Design Tokens)
  layout.css        الحاويات، الشبكة، قسم الهيرو
  components.css    شريط التنقل، الأزرار، البطاقات، المعرض، صندوق العرض، التواصل
  animations.css    حالات الحركة الابتدائية وKeyframes
  responsive.css    نقاط التوقف لكل فئة أجهزة
js/
  app.js            نقطة الدخول: شاشة التحميل، Lenis، تشغيل الوحدات
  navigation.js      شريط التنقل، القائمة الجوّالة، مؤشر التمرير
  animations.js      GSAP + ScrollTrigger: كشف الهيرو، الكشف عند التمرير، الأزرار المغناطيسية، المؤشر المخصص
  portfolio.js        شبكة الأعمال (Masonry)، الفلاتر، صندوق العرض الكامل (Lightbox)
assets/
  images/            جميع صور المعرض + الشعار (36 عملاً موزّعة على 6 قطاعات)
  icons/             (فارغ — الأيقونات الحالية SVG مضمّنة مباشرة داخل HTML)
  fonts/             (فارغ — الخطوط محمّلة عبر Google Fonts)
README.md
```

## التشغيل محليًا

لا حاجة لأي أدوات بناء (build tools). يكفي خادم ثابت بسيط لأن الصفحة تستخدم `type="module"`:

```bash
# باستخدام بايثون
python3 -m http.server 8000

# أو باستخدام Node
npx serve .
```

ثم افتح `http://localhost:8000` في المتصفح.

> فتح `index.html` مباشرة بنقرتين (file://) قد يمنع المتصفح من تحميل الوحدات (ES Modules) بسبب سياسة CORS المحلية — لذلك يُفضّل خادم محلي بسيط كما بالأعلى.

## المكتبات الخارجية (عبر CDN فقط)

- **GSAP + ScrollTrigger** — محرك الحركة الأساسي
- **Lenis** — التمرير السلس
- **qrcodejs** — توليد رمز الاستجابة السريعة لرابط الموقع في قسم التواصل

لا حزم npm ولا خطوة تثبيت مطلوبة.

## نشر الموقع

الموقع ملفات ثابتة بالكامل — يمكن رفعه كما هو إلى Netlify, Vercel, GitHub Pages, أو أي استضافة ثابتة، أو ربطه بنطاق `abuadeeb-design.carrd.co` إذا اعتُمد كخادم ثابت مخصص.

## التخصيص السريع

- **الألوان والطباعة**: كل القيم في `css/style.css` أعلى الملف داخل `:root`.
- **صور المعرض**: أضف/استبدل ملفات JPG داخل `assets/images/` باتّباع نمط التسمية `<قطاع>-<رقم>.jpg`، ثم حدّث العدد في `COUNTS` داخل `js/portfolio.js`.
- **بيانات التواصل**: الإيميل، حسابات التواصل، ورابط الموقع موجودة مباشرة داخل `index.html` (قسم `#contact`) وداخل `js/app.js` (توليد QR).

## إمكانية الوصول والأداء

- دعم `prefers-reduced-motion` لتعطيل الحركات لمن يفضّل ذلك.
- تركيز لوحة مفاتيح ظاهر (`:focus-visible`) على كل العناصر التفاعلية.
- تنقّل كامل بالكيبورد داخل صندوق العرض الكامل (الأسهم، Escape).
- تحميل كسول (`loading="lazy"`) لصور المعرض.
- بيانات Schema.org (JSON-LD) وOpen Graph وTwitter Cards جاهزة لمحركات البحث.
